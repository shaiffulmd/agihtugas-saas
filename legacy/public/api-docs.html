Kontrak OpenAPI

Base URL: /api/v1. Semua endpoint memerlukan Authorization: Bearer <API_KEY>. Cipta key daripada terminal pelayan:

php bin/api-key.php create 'koku-multi' write

Key penuh dipaparkan sekali sahaja. Simpan pada backend koku-multi; jangan letakkan dalam pelayar. Skop read untuk bacaan dan write untuk bacaan serta perubahan. Arahan list dan revoke ID mengurus akses.

Integrasi koku-multi

Klien PHP disediakan dalam integrations/koku-multi/AgihTugasClient.php, bersama panduan pemasangan. Ia belum diaktifkan dalam koku-multi. Rujukan koku-multi:{school_id}:{user_id} mengelakkan pendua semasa sync berulang.

Satu ruang kerja AgihTugas untuk satu sekolah. Key berbeza dalam ruang kerja yang sama berkongsi data; ia bukan pengasingan sekolah. UI menggunakan log masuk dan peranan. API tidak boleh meluluskan agihan; semua perubahan API disekat apabila status bukan Draf.

Badan JSON maksimum 64 KB. Senarai menyokong page dan per_page (maksimum 100). Respons mempunyai data dan request_id; ralat mempunyai error.code dan error.message. Dokumentasi penuh: docs/API.md.
